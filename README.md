# 悬臂式人机协同装配机器人力控系统

面向航空结构件预装配与人工牵引作业开发的实时柔顺控制程序。系统基于纳博特/NexRob 运动控制平台，通过 EtherCAT PDO 读取六维力传感器数据，在 1 kHz 控制循环中完成信号处理、四自由度导纳运算、坐标变换、机器人逆解与关节目标下发，实现末端平移牵引和绕 Z 轴旋转调整的解耦控制。

当前开源代码对应真机牵引控制主链路，控制维度为 `[x, y, z, Rz]`。

## 系统架构

```mermaid
flowchart LR
    A[双量程六维力传感器] --> B[EtherCAT PDO]
    B --> C[零偏 / 低通滤波<br/>连续死区 / 幅值保护]
    C --> D{操作模式}
    D -->|平移模式| E[Fx Fy Fz]
    D -->|旋转模式| F[Mz]
    E --> G[四自由度导纳控制]
    F --> G
    G --> H[工具系到基座系投影]
    H --> I[控制器逆运动学]
    I --> J[ServoJ 关节跟踪]
    J --> K[4 轴伺服机构]
```

## 核心功能

### 1. 1 kHz 实时控制循环

- 力控开启后以 `1 ms` 为周期运行，非力控状态降为 `10 ms` 轮询。
- 使用 `CLOCK_MONOTONIC + TIMER_ABSTIME` 绝对定时，降低相对休眠造成的周期累计漂移。
- 通过 `mlockall` 锁定进程内存，并将主控制线程设置为 `SCHED_FIFO`、优先级 80。
- 传感器状态回传使用独立低优先级线程，避免非关键任务阻塞主控制循环。

### 2. 双量程六维力传感器

- 通过 EtherCAT PDO 映射同时读取大量程和小量程六维力传感器。
- 启动力控或收到清零指令时，对两个传感器分别进行 50 点零偏估计。
- 运行中可切换传感器；切换时清空滤波状态并将导纳速度复位，减少不同零点和噪声水平引起的目标跳变。
- 对输入依次执行一阶低通滤波、连续死区和幅值限制，抑制噪声、边界突变与异常尖峰。

### 3. 平移/旋转解耦牵引

- 平移模式仅使用 `[Fx, Fy, Fz]`，屏蔽 `Mz`，实现三维人工牵引。
- 旋转模式仅使用 `Mz`，锁定切换瞬间的平移偏移，实现原位姿态微调。
- 模式切换时保存当前位置、清零导纳速度，并锁定参考姿态，降低切换冲击。

### 4. 四自由度导纳控制

控制器在 `[x, y, z, Rz]` 四个方向上实现离散导纳模型：

```text
M·ẍ + D·ẋ + K·(x − x_d) = F_ext
```

外力经过滤波和保护后驱动虚拟质量—阻尼系统，积分得到末端位置与角度偏移。各轴设置独立虚拟质量、阻尼及速度上限，防止异常外力产生过大的运动指令。

### 5. 运动学与安全保护

- 将工具坐标系中的平移偏移实时投影到机器人基座坐标系。
- 调用 NexRob 控制器接口完成 MCS 到 ACS 的逆运动学，并通过 `NRC_Set_ServoJ_Pos` 下发关节目标。
- 逆解失败、状态读取失败、关节超限或目标发送失败时自动关闭力控请求。
- 停止时先关闭关节跟踪，确认机器人运行状态为停止且关节位置持续稳定，再执行伺服下使能。
- 每次重新开启力控均重新读取基准位姿、清零导纳状态和滤波状态，避免继承上一轮速度。

## 关键参数

| 参数 | 当前代码默认值 |
|---|---:|
| 力控周期 | 1 ms（1 kHz） |
| 导纳虚拟质量 `M` | `[130, 130, 120, 5]` |
| 导纳阻尼 `D` | `[4000, 3000, 5000, 120]` |
| 导纳刚度 `K` | `[0, 0, 0, 0]` |
| 平移速度上限 | X/Y：0.05 m/s，Z：0.03 m/s |
| 旋转速度上限 | 0.174533 rad/s（约 10°/s） |
| 力输入上限 | ±80 N |
| 力矩输入上限 | ±2 N·m |
| 小量程传感器死区 | 1 N / 0.2 N·m |
| 大量程传感器死区 | 2 N / 0.5 N·m |
| 力信号滤波 | `alpha = 0.06`，代码注释约 10 Hz |

这些参数与机构惯量、负载和现场操作手感有关，真机使用前需要重新辨识与验证。

## I/O 约定

| 信号 | 作用 |
|---|---|
| `BoolVar 1` | 力控启停 |
| `BoolVar 2` | 传感器清零 |
| `BoolVar 5` | 大/小量程传感器选择 |
| `BoolVar 4` | 关节超限报警 |
| `DI Board 1 / Channel 1` | 平移/旋转模式切换 |
| `DoubleVar 7–18` | 两组六维力原始数据状态回传 |

## 代码结构

| 文件/目录 | 作用 |
|---|---|
| `src/main.cpp` | 系统初始化、实时调度与程序入口 |
| `src/ControlLoop.cpp` | 1 kHz 主控制循环、模式切换、控制器调用与安全逻辑 |
| `src/Admittance.cpp` | 四自由度离散导纳控制器及速度限幅 |
| `src/RobotUtils.cpp` | 控制器启动、PDO 映射、传感器清零、状态读取和逆解封装 |
| `src/AsyncLogger.cpp` | 异步运行日志 |
| `include/` | 工程头文件及 NexRob SDK 接口 |
| `lib/libNexRob.a` | NexRob 厂商静态库（公开前需确认再分发许可） |
| `Makefile` | 32 位 Linux/C++11 编译配置 |

## 编译与运行

### 环境要求

- Linux 实时运行环境；
- 支持 32 位编译的 GCC/G++ 工具链；
- 纳博特/NexRob 控制器及与当前 SDK 匹配的运行库；
- EtherCAT 总线、伺服系统和已完成 PDO 配置的六维力传感器；
- 允许执行实时调度与内存锁定的系统权限。

```bash
make
sudo ./nrc2.out
```

> 该程序会连接真实运动控制器并下发伺服目标。运行前必须核对关节方向、机械限位、急停回路、传感器符号和 EtherCAT 从站映射，并先在低速、空载条件下完成验证。
